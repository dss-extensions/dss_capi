# AltDSS Oddie

*OpenDSSDirect.DLL Interface Extender for EPRI's OpenDSS binaries*

**Oddie** wraps and extends **EPRI's OpenDSSDirect.DLL** binaries (a.k.a. DCSL) with the same API that our other 
projects use, as defined in AltDSS/DSS C-API. These include OpenDSS and OpenDSS-C variations.

**[Documentation available in the hub repository](https://github.com/dss-extensions/dss-extensions/blob/main/docs/oddie.md)**
