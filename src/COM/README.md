# DSS-Extensions COM Bridge DLL

This folder contains the source code for the DSS-Extensions COM DLL, introduced in April 2025.

This DLL does not implemented the engines, just expose existing C-compatible libraries to Microsoft's Component Object Model (COM), by using DSS-Extensions AltDSS/DSS C-API and Oddie subprojects.

**[Documentation available in the hub repository](https://github.com/dss-extensions/dss-extensions/blob/main/docs/dss-extensions-com-dll.md)**
